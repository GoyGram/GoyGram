# GoyGram Code of Conduct

## Our standard

GoyGram contributors are expected to be respectful, technical, and constructive. We welcome reports that improve Telegram protocol correctness, security, reliability, accessibility, and documentation.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, deliberate credential disclosure, malicious code, and knowingly submitting misleading security or compatibility claims.

## Enforcement

Project maintainers may remove comments, reject changes, or restrict participation when this code is violated. Report conduct concerns privately to the maintainers rather than publishing personal information or secrets.

This policy applies in project issues, pull requests, discussions, reviews, and project-managed communication spaces.
